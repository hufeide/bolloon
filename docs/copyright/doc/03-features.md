# 第三章 功能规格说明

本章逐项说明软件的功能规格。编号规则为「F-模块-序号」，每项包含功能描述、输入、处理、输出与异常处理。

## 3.1 会话与消息

1. F-CHAT-1 创建与切换会话
   - 功能描述：用户可创建多个会话，按智能体或主题隔离上下文，随时切换与检索历史会话。
   - 输入：会话名称（可选）、归属智能体、初始消息（可选）。
   - 处理：生成会话标识，写入会话索引，初始化该会话的消息列表与上下文视窗。
   - 输出：会话标识与初始界面状态。
   - 异常处理：写入失败时保留内存态并提示；重复名称自动追加序号，不覆盖既有会话。
2. F-CHAT-2 发送消息与流式返回
   - 功能描述：发送消息后界面即时受理，回复以流式方式逐步显示，并同步展示执行轨迹。
   - 输入：文本消息，可附带文件引用、技能引用、渠道引用。
   - 处理：服务端受理后返回受理状态，随后通过事件流推送文本增量、工具状态、步骤事件与最终答复。
   - 输出：受理状态；流式内容；最终答复与本次执行的完整轨迹。
   - 异常处理：模型不可用时返回可读错误并保留已产生内容；事件流中断时界面提示可重试。
3. F-CHAT-3 中断与继续
   - 功能描述：用户可中断正在执行的任务，也可让被中断的任务继续。
   - 输入：中断指令或继续指令。
   - 处理：中断时终止当前迭代循环并保留已完成的工具结果；继续时从保留状态恢复循环。
   - 输出：中断确认与当前状态；继续后的新回复。
   - 异常处理：对已结束任务的中断指令返回「无需中断」，不产生副作用。
4. F-CHAT-4 会话分支与消息操作
   - 功能描述：支持对某条回复进行复制、评价、重新生成与分支，分支会以该条消息为起点新建会话。
   - 输入：目标消息标识与操作类型。
   - 处理：复制写入剪贴板数据；重新生成从该条消息的上一条重跑；分支复制截至该条的消息序列到新会话。
   - 输出：操作结果与新会话（分支时）。
   - 异常处理：目标消息不存在时提示并保持原状态。

## 3.2 多模型接入与配置

1. F-LLM-1 供应商与模型配置
   - 功能描述：用户在本机配置大模型供应商、密钥、模型名称与接口地址，随时切换。
   - 输入：供应商、密钥、模型名称、接口地址、可选参数。
   - 处理：校验必填项后写入本机配置文件，密钥仅存本机，界面回显时脱敏。
   - 输出：配置结果与连通性检测结论。
   - 异常处理：密钥缺失时状态停在「待填凭证」并给出明确下一步；配置损坏时进入待修复状态，不静默回退默认值。
2. F-LLM-2 初始化向导与就绪判定
   - 功能描述：首次启动引导用户完成身份、供应商、密钥、模型与连通性检查，形成可恢复的初始化过程。
   - 输入：用户逐项选择与填写。
   - 处理：按阶段推进初始化状态机，每阶段结果落盘；中断后可从已完成阶段继续，未就绪状态下不允许创建长期任务。
   - 输出：就绪状态与各阶段结果。
   - 异常处理：连通性失败按错误类型分类（凭证错误、网络不可达、限流等），并给出对应恢复动作。
3. F-LLM-3 请求重试与降级
   - 功能描述：模型请求失败时按错误类型自动重试，必要时切换备用模型。
   - 输入：请求失败结果与当前配置。
   - 处理：区分可重试与不可重试错误，按退避策略重试；超过阈值后切换到备用模型或转人工。
   - 输出：重试结果与降级选择记录。
   - 异常处理：全部失败时如实报告失败原因与已尝试路径。

## 3.3 工具调用

1. F-TOOL-1 工具注册与清单查询
   - 功能描述：软件内置大量工具，按需注册到当前会话；用户可查询可用工具与用法。
   - 输入：查询指令或空（列出全部）。
   - 处理：汇总内置工具与扩展工具（补丁、桌面操作、浏览器、人机问答、技能分享、模型上下文协议、支付等）。
   - 输出：工具名称、用途与参数说明清单。
   - 异常处理：无可列内容时返回空清单说明。
2. F-TOOL-2 参数校验与执行
   - 功能描述：工具执行前校验参数类型与必填项，执行后返回结构化结果。
   - 输入：工具名称与参数对象。
   - 处理：校验参数（缺失或类型错误直接拒绝并给出期望格式）→ 经权限闸门判定 → 执行 → 记录审计。
   - 输出：成功结果或带原因的错误结果。
   - 异常处理：参数非法不执行工具本体；执行超时终止并保留现场；重复调用按幂等键去重。
3. F-TOOL-3 文件与命令操作
   - 功能描述：提供文件读取、写入、编辑、移动、删除、目录列举、内容检索（按名与按内容）等能力，以及命令执行能力。
   - 输入：路径、内容、匹配模式、命令与参数。
   - 处理：写入走「写临时文件再原子替换」；命令执行限制工作目录与超时。
   - 输出：操作结果、执行输出与退出状态。
   - 异常处理：越权路径与拒绝清单内的命令直接拒绝；路径不存在时给出可读原因。
4. F-TOOL-4 代码与工程工具
   - 功能描述：提供类型检查、单元测试执行、版本库操作（状态、差异、提交、分支、储藏）与工程校验能力。
   - 输入：工程路径与操作参数。
   - 处理：在工程目录内执行对应命令，收集输出与退出码。
   - 输出：检查或测试结论、差异内容、提交结果。
   - 异常处理：测试失败如实返回失败用例数与摘要，不把失败当作成功。
5. F-TOOL-5 人机问答
   - 功能描述：当智能体需要用户补充信息时，可主动提问并暂停等待回答；选项可渲染为可点击项。
   - 输入：问题文本、选项列表、超时时间。
   - 处理：提问后登记等待；命令行直接输入回答，浏览器与移动端通过事件流与回答接口提交。
   - 输出：用户回答；超时记录。
   - 异常处理：无人类界面时如实拒绝（不伪造答案）；超时返回超时结论，不编造回答。
6. F-TOOL-6 浏览器与桌面操作
   - 功能描述：可打开网页并提取文本、链接、页面结构、截图，可执行点击与输入；桌面端可截图、点击、输入、切换前台应用。
   - 输入：网址、元素定位信息、坐标、文本。
   - 处理：浏览器能力以本地无头浏览器与调试协议实现，空闲自动回收；桌面能力在获得系统授权后执行。
   - 输出：页面内容、截图文件、操作结果。
   - 异常处理：未授权时给出人话提示引导授权；元素未找到时返回候选元素清单供重试。

## 3.4 文档处理与知识库

1. F-DOC-1 文档解析
   - 功能描述：解析常见文档格式（便携文档、文字处理文档、源代码文件）并抽取正文。
   - 输入：文件路径或二进制内容。
   - 处理：按格式选择解析器，抽取正文与元信息。
   - 输出：正文文本与元信息。
   - 异常处理：格式不支持或内容加密时给出可读原因。
2. F-DOC-2 文档接收与签名核验
   - 功能描述：接收点对点网络传来的文档，核验发送方签名与内容完整性后入库。
   - 输入：入站文档帧（含发送方身份、签名、内容标识）。
   - 处理：验签 → 计算内容标识 → 入库并建立索引。
   - 输出：入库结果与文档标识。
   - 异常处理：验签失败或内容标识不匹配时拒绝入库并记录。
3. F-DOC-3 文档处理助手
   - 功能描述：对文档执行摘要与改写建议，结果可回写为新版本而不破坏原文。
   - 输入：文档路径与处理类型。
   - 处理：先做路径与权限前置校验，再读取内容、生成结果、按需另存。
   - 输出：摘要或改写结果与产物路径。
   - 异常处理：路径缺失等参数错误在读取前拦截，避免底层异常直接暴露。
4. F-DOC-4 知识整理
   - 功能描述：按心跳或手动触发，把会话中的稳定结论整理为知识条目，并可整理技能与记忆。
   - 输入：触发指令或定时触发。
   - 处理：抽取候选条目 → 去重与合并 → 写入知识库并回填索引。
   - 输出：整理结果（新增、合并、跳过条目数）。

## 3.5 记忆与上下文管理

1. F-MEM-1 分层记忆
   - 功能描述：把记忆分为人格层、项目层、会话层与知识层，按优先级装配进上下文。
   - 输入：当前会话状态与用户消息。
   - 处理：按层读取、按优先级裁剪、按预算装配；超出预算时先折叠会话层再压缩知识层。
   - 输出：装配后的上下文与各层占用统计。
   - 异常处理：某一层缺失时跳过并在统计中标注，不阻断对话。
2. F-MEM-2 上下文压缩与快照
   - 功能描述：上下文接近窗口上限时自动压缩，并保留压缩前快照以便追溯。
   - 输入：当前消息序列与预算参数。
   - 处理：折叠已完成工具片段 → 摘要历史消息 → 按预算截断；快照落盘。
   - 输出：压缩后的上下文、压缩比例与快照标识。
   - 异常处理：摘要失败时退化为截断并标注，不丢失最近若干轮对话。
3. F-MEM-3 记忆回读
   - 功能描述：回答前按需回读本机记忆与知识条目，减少重复提问。
   - 输入：当前问题与检索范围。
   - 处理：多路检索（关键词、向量、图谱）后合并排序，取前若干条注入上下文。
   - 输出：命中的记忆条目与来源。
   - 异常处理：无命中时返回空结果，避免编造来源。

## 3.6 技能体系

1. F-SKILL-1 技能加载
   - 功能描述：从本机技能目录与扩展目录加载技能描述文件，兼容两种元信息写法。
   - 输入：技能目录路径集合。
   - 处理：解析元信息（名称、版本、适用范围、触发条件）与正文；正文作为知识注入上下文。
   - 输出：可用技能清单与各自元信息。
   - 异常处理：解析失败的文件跳过并在报告中列出，不阻断其他技能加载。
2. F-SKILL-2 技能使用
   - 功能描述：按触发条件选用技能，或由用户显式调用技能。
   - 输入：任务描述或技能名称。
   - 处理：匹配适用技能 → 注入正文 → 按技能内的工作流执行。
   - 输出：执行结果与所用技能记录。
   - 异常处理：技能不存在或未启用时给出候选清单。
3. F-SKILL-3 技能导入与事务性替换
   - 功能描述：从技能包导入技能，导入过程具备事务性，中途失败可回滚可恢复。
   - 输入：技能包（本地文件或内容寻址链接）。
   - 处理：预备校验（名称、路径安全、元信息、版本门）→ 写暂存 → 原子替换（旧版本保留备份）→ 读回校验 → 登记。
   - 输出：导入结果与版本信息。
   - 异常处理：失败回滚且登记表不变，失败原因可查；进程被强制终止后重启可清理残留并恢复备份。
4. F-SKILL-4 技能分享与沉淀
   - 功能描述：把技能目录打包为技能包并上传到内容寻址存储，得到分享链接；也可从链接导入。
   - 输入：技能名称与打包范围。
   - 处理：打包（元信息加引用资料）→ 上传 → 生成分享链接；可顺带通过点对点通道发送给好友。
   - 输出：分享链接与技能包标识。
   - 异常处理：本地版本不低于来源版本时拒绝覆盖（除非显式强制），避免静默降级。
5. F-SKILL-5 技能快照门禁
   - 功能描述：长期任务在执行前冻结所用技能的快照并校验，防止执行中技能被替换导致行为漂移。
   - 输入：目标声明的所需技能。
   - 处理：冻结（名称、版本、内容指纹、来源、冻结时间）→ 启动运行前校验存在、启用、可用与指纹一致。
   - 输出：校验结论；不通过时不启动运行并转人工。
   - 异常处理：技能漂移需人工批准后才允许升级；可选技能缺失只降级不阻断。

## 3.7 长期任务与目标

1. F-GOAL-1 目标创建与判据
   - 功能描述：用户提出目标，软件记录完成判据；用户未给判据时软件提出候选判据并请求确认。
   - 输入：目标描述、判据（可选）、所需技能（可选）。
   - 处理：写入目标库；候选判据标注为未确认。
   - 输出：目标标识与判据状态。
   - 异常处理：判据过于模糊时交人工澄清，不伪造判据；未就绪状态下拒绝创建目标。
2. F-GOAL-2 运行与监督
   - 功能描述：监督器按目标生成运行并监控执行，支持暂停、恢复、中止与人工接管。
   - 输入：目标标识与操作指令。
   - 处理：生成运行并冻结判据 → 执行 → 汇总证据 → 判定是否完成。
   - 输出：运行结果与证据清单。
   - 异常处理：同一目标不允许被两个执行者同时认领；非幂等操作重放时被守卫拦截。
3. F-GOAL-3 失败重试与自动唤醒
   - 功能描述：运行等待外部条件时登记等待并在条件满足或到期时被唤醒。
   - 输入：等待条件（来源、关联标识、事件类型、超时）。
   - 处理：到点检查并清除等待，满足条件则进入下一轮；否则转人工。
   - 输出：唤醒结果或转人工结论。
   - 异常处理：事件来源与关联不匹配、事件过期、事件重复均不唤醒，并留下判定记录。
4. F-GOAL-4 长期执行面板
   - 功能描述：界面展示目标、运行、监督器状态，支持确认判据、提交候选判据、唤醒、暂停与中止。
   - 输入：界面操作。
   - 处理：调用目标接口读取与写入状态。
   - 输出：面板数据与操作结果。
   - 异常处理：目标已结束时的操作返回「无需操作」，不产生副作用。

## 3.8 定时任务与运行态

1. F-CRON-1 定时任务
   - 功能描述：支持周期性任务与一次性任务，按计划触发。
   - 输入：计划表达式与任务内容。
   - 处理：单实例调度，触发前取锁防止重复执行，执行记录写入日志。
   - 输出：执行记录与结果摘要。
   - 异常处理：锁竞争时本轮跳过；任务超时终止；连续失败触发熔断并暂停该任务。
2. F-CRON-2 勿扰与主任务优先
   - 功能描述：主任务执行期间或用户设定的安静时段内，定时任务不打扰；被推迟的任务在主任务结束后补跑。
   - 输入：安静时段配置与主任务状态。
   - 处理：检测到主任务占用时把到点任务标记为推迟；主任务结束后触发补跑。
   - 输出：推迟与补跑记录。
   - 异常处理：安静时段配置损坏时按不打扰处理（保守侧）。
3. F-HB-1 心跳与存活观测
   - 功能描述：周期性检查智能体与网络状态，异常时记录并可上报界面。
   - 输入：检查周期与目标清单。
   - 处理：检查存活、连接数与任务进度，写入心跳日志。
   - 输出：心跳记录与状态摘要。
   - 异常处理：检查失败只记录不静默退出；避免把「无响应」误判为失败。

## 3.9 点对点网络与身份

1. F-P2P-1 节点发现与连接
   - 功能描述：自动发现同网段与其他网络中的节点并建立连接，跨网段时通过中继转发。
   - 输入：网络配置与可选的引导节点、中继地址。
   - 处理：启动网络节点 → 广播自身地址 → 定期探活与重连 → 跨网段时申请中继保留并在启动后复验中继协议可用。
   - 输出：已连接节点列表、自身可拨入地址列表、连接质量状态。
   - 异常处理：无公网环境时进入离线模式并如实提示；中继不可用时降级为仅局域网。
2. F-P2P-2 身份与签名
   - 功能描述：为节点生成去中心化身份，节点间消息签名与验签。
   - 输入：节点身份文件（首次自动生成）；入站签名消息。
   - 处理：生成密钥对与身份标识 → 出站消息签名 → 入站消息先验签再进入业务处理。
   - 输出：身份标识与公钥；验签结论。
   - 异常处理：验签失败的消息丢弃并记录；身份文件损坏时给出修复指引，不静默重建导致身份变更。
3. F-P2P-3 消息与文档传输
   - 功能描述：支持点对点会话消息、广播消息、渠道消息与文档传输。
   - 输入：目标节点、消息内容或文档。
   - 处理：选择链路（直连或中继）→ 分片传输 → 接收端确认与去重。
   - 输出：投递结果与回执。
   - 异常处理：对端不可达时返回明确错误；重复消息按标识去重。
4. F-P2P-4 任务委派
   - 功能描述：把任务委派给具备相应能力且处于可用状态的对端智能体执行。
   - 输入：能力要求、任务描述、超时。
   - 处理：严格按能力匹配选择执行者 → 投递 → 对端真实执行 → 返回产物与内容标识。
   - 输出：执行者标识、产物内容标识与执行结果。
   - 异常处理：能力不匹配时不转派其他智能体，明确返回无匹配；对端无响应按超时处理；无可用执行器时不返回伪造产物标识。
5. F-P2P-5 入网与网关
   - 功能描述：节点可加入全局智能体网络（网关），登记自身能力清单并被其他节点发现。
   - 输入：入网说明文档地址或网关地址。
   - 处理：读取入网说明 → 登记身份与能力 → 落盘入网状态（重启后仍可读）→ 通过网关被检索。
   - 输出：入网状态、被登记的能力清单与分享链接。
   - 异常处理：入网说明不可读时返回失败原因；登记中心不可用时如实说明未生成分享链接，不伪造成功。

## 3.10 社交、群组与多设备

1. F-SOC-1 好友关系
   - 功能描述：通过标识或附近设备发起好友申请，对方可接受或忽略。
   - 输入：对方标识、申请消息。
   - 处理：申请入队并可查询待处理列表 → 接受后建立双向关系 → 之后可直接互发消息与文档。
   - 输出：关系状态与待处理申请清单。
   - 异常处理：重复申请去重；对方离线时申请保留待处理。
2. F-SOC-2 群组与广播
   - 功能描述：把多个节点组成群组，群内消息按组广播。
   - 输入：群组成员与群组消息。
   - 处理：维护群组清单 → 逐成员投递 → 汇总投递结果。
   - 输出：群组清单与投递结果。
   - 异常处理：成员不可达时保留消息并可重投。
3. F-SOC-3 多设备登记与同步
   - 功能描述：同一身份下的多台设备互相登记，可同步会话与目录。
   - 输入：设备身份与同步范围。
   - 处理：登记设备 → 按标识同步增量 → 冲突时按时间与来源合并。
   - 输出：设备清单与同步结果。
   - 异常处理：同步中断时下次续传，不产生半份数据。

## 3.11 多端界面与移动端能力

1. F-UI-1 命令行界面
   - 功能描述：终端交互界面，包含输入区、状态区、执行轨迹区与命令补全。
   - 输入：终端输入与命令。
   - 处理：渲染消息列表与步骤状态，支持引用输入与历史检索。
   - 输出：渲染后的界面与命令结果。
   - 异常处理：终端尺寸变化时自适应重绘；渲染异常时降级为纯文本输出。
2. F-UI-2 浏览器界面
   - 功能描述：浏览器中提供会话、智能体、网络、技能、目标、设置等页面。
   - 输入：浏览器操作。
   - 处理：调用本机服务端接口；事件流驱动实时更新。
   - 输出：页面数据与交互结果。
   - 异常处理：服务不可达时给出明确提示；兼容模式下降级为轮询。
3. F-UI-3 桌面客户端
   - 功能描述：以桌面外壳封装服务端与界面，双击即用。
   - 输入：应用启动与窗口操作。
   - 处理：启动时选择空闲端口并拉起服务，窗口加载本地界面。
   - 输出：可用的桌面应用。
   - 异常处理：端口被占用时自动换端口；启动超时给出日志位置指引。
4. F-UI-4 移动端界面与本地智能体
   - 功能描述：移动端提供会话、好友、网络、技能、支付、设置等页面，并可在本机执行智能体循环。
   - 输入：触摸操作与语音或文本输入。
   - 处理：本地页面容器内运行界面逻辑，本机保存会话与消息；智能体循环在本机执行并回传执行轨迹。
   - 输出：界面状态、回复与执行轨迹。
   - 异常处理：本机执行环境不可用时明确提示并引导到设置页。
5. F-UI-5 扫码入网与附近设备
   - 功能描述：移动端可通过扫描桌面端二维码或选择附近设备加入网络，并处理待通过的好友申请。
   - 输入：二维码内容或附近设备列表项。
   - 处理：解析连接信息 → 建立连接 → 登记入网状态；桌面不可达时给出替代路径。
   - 输出：连接结果与网络状态。
   - 异常处理：二维码无效或过期时提示重新获取。
6. F-UI-6 无障碍自动操作
   - 功能描述：在用户于系统设置中授权后，智能体可代用户操作本机界面（点击、滑动、返回、输入、读取界面元素）。
   - 输入：智能体下达的操作指令。
   - 处理：在主线程执行手势并等待完成回调；读取界面元素前先判断服务是否就绪。
   - 输出：操作结果与界面元素快照。
   - 异常处理：未授权或未就绪时如实提示「仅真机并授权后可用」；操作超时终止。
7. F-UI-7 隐私同意与数据清除
   - 功能描述：首次启动弹出隐私政策同意门；设置页提供隐私政策与「清除本机数据（注销）」入口。
   - 输入：同意或不同意；清除指令。
   - 处理：同意前不初始化任何功能、不连网、不申请权限；清除时删除本机身份、智能体、会话与消息、支付记录与本机键值。
   - 输出：同意记录；清除结果。
   - 异常处理：选择不同意时停留在说明页，不崩溃、不强制退出、不收集信息。

## 3.12 支付与微支付信息服务（可选）

1. F-PAY-1 钱包与余额
   - 功能描述：在用户显式启用并导入钱包后，可查询余额、签名消息、发起转账与合约调用。
   - 输入：钱包凭证、目标地址、金额。
   - 处理：本地签名 → 提交网络 → 记录交易。
   - 输出：交易标识与状态。
   - 异常处理：未启用钱包时相关工具直接拒绝，不隐式创建钱包。
2. F-PAY-2 微支付信息服务
   - 功能描述：支持按次付费获取信息，并对待核验信息做验真。
   - 输入：信息条目标识或查询条件。
   - 处理：发起付费请求 → 校验支付要求与额度 → 获取内容 → 生成验真信封。
   - 输出：信息内容与验真结论。
   - 异常处理：额度不足或支付被拒绝时明确失败原因，不返回未付费内容。

## 3.13 自我改进与更新

1. F-UP-1 版本检查与更新
   - 功能描述：检查是否有新版本并可按用户指令更新。
   - 输入：检查指令。
   - 处理：读取远端版本号 → 与本地比对 → 输出差异；更新时按安装方式选择升级路径。
   - 输出：版本结论与更新结果。
   - 异常处理：网络不可达时如实提示，不阻塞主流程。
2. F-UP-2 自我改进与质量门控
   - 功能描述：对软件自身做改进尝试，改动前经过质量门控（类型检查、测试、校验脚本）。
   - 输入：改进方向。
   - 处理：生成改动 → 在临时副本上执行门控 → 通过才落地，不通过回滚。
   - 输出：改进结果与门控结论。
   - 异常处理：门控不通过时保留原状并如实报告失败项。
   - 异常处理：无可整理内容时如实返回零结果。
