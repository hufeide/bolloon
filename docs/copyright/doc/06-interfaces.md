# 第六章 接口设计

## 6.1 接口总览

软件对外接口分四类：一是命令行接口（56 个开关与子命令），二是本机 HTTP 接口（服务端共 236 条路由声明，方法分布为查询 106 条、提交 109 条、更新 9 条、删除 9 条、部分更新 3 条），三是工具接口（智能体可调用的工具共约 150 个），四是节点间协议接口（点对点消息、文档、委派、唤醒）。

## 6.2 命令行接口

| 类别 | 开关（节选） | 说明 |
| --- | --- | --- |
| 运行形态 | `--web`、`--tui`、`--cli`、`--supervise`、`--supervise-once`、`--supervise-dry-run` | 选择浏览器模式、终端界面、纯命令行、长期任务监督及其单次与演练模式 |
| 初始化 | `--setup-status`、`--setup-resume`、`--setup-repair`、`--setup-reconfigure`、`--setup-test` | 查询初始化状态、继续中断的初始化、修复损坏配置、重新配置、连通性测试 |
| 身份与网络 | `--identity`、`--peers`、`--broadcast`、`--global-agents`、`--register-agent`、`--send` | 查看身份、节点列表、广播消息、全局智能体检索、登记与发送 |
| 会话与渠道 | `--chat-init`、`--chat-list`、`--chat-send`、`--chat-pull`、`--chat-watch`、`--chat-status` | 会话仓库的初始化、列举、发送、拉取、监听与状态 |
| 文档与知识 | `--read`、`--summarize`、`--improve`、`--search`、`--context`、`--agents` | 读取、摘要、改进、检索、上下文与智能体清单 |
| 模型与工具 | `--model`、`--tools`、`--engine`、`--delegate`、`--collab` | 模型配置与切换、工具清单、外部引擎、任务委派、协作 |
| 运行框架 | `--harness-init`、`--harness-check`、`--harness-gate`、`--harness-session-context`、`--harness-skill`、`--harness-sessions`、`--harness-archive`、`--harness-classify`、`--harness-transition` | 运行框架的初始化、校验、门禁、会话上下文、技能、会话清单、归档、分类与状态迁移 |
| 更新与输出 | `--update-check`、`--update-now`、`--json`、`--logs`、`--output`、`--limit`、`--interval` | 检查与执行更新、结构化输出、日志、输出路径、数量与周期限制 |
| 其他 | `--help`、`--with`、`--prompt`、`--add-action`、`--iroh` | 帮助、附加参数、一次性提示词、追加动作、点对点传输开关 |

## 6.3 本机 HTTP 接口

服务端默认监听本机端口，按功能域分组的主要接口如下（均为相对路径）：

| 功能域 | 代表接口 | 说明 |
| --- | --- | --- |
| 会话与消息 | 会话列表与详情、消息提交、消息流（事件流）、中断与继续、问题回答 | 消息提交立即返回受理状态，内容经事件流推送 |
| 智能体 | 智能体列表、创建、更新、删除、状态 | 管理本机智能体及其身份与能力 |
| 模型配置 | 配置读取与写入、连通性测试、模型切换、密钥写入 | 写入时脱敏，密钥仅存本机 |
| 工具与技能 | 工具清单、工具调用、技能清单、技能导入导出、技能分享 | 支持按名称调用与批量导入 |
| 目标与长期执行 | 目标列表、目标详情、判据读取与写入、唤醒、暂停、恢复、中止 | 支撑长期执行面板 |
| 网络与节点 | 节点列表、入网、连接信息、二维码内容、附近设备、好友申请与通过 | 支撑扫码入网与好友流程 |
| 文档与知识 | 文档列表与详情、上传、解析、知识条目、记忆检索 | 文档以内容标识寻址 |
| 数据快照 | 本机数据快照、桌面端同步、移动端快照 | 支撑移动端展示与同步 |
| 支付（可选） | 钱包状态、余额、支付记录、微支付信息购买与验真 | 仅在用户启用后可用 |
| 系统 | 版本检查、日志、健康检查、事件流、移动端网关 | 运行观测与移动端通道 |

## 6.4 工具接口

工具接口统一形式为「工具名 + 参数对象 + 结构化结果」。按功能分组的主要工具（共约 150 个）：

1. 文件与目录：读取、写入、编辑、删除、移动、建目录、列举、按名检索、按内容检索。
2. 命令与代码：命令执行、代码执行、类型检查、单元测试、补丁应用、版本库操作（状态、差异、提交、推送、分支、储藏、恢复）。
3. 文档：文档读取、摘要、改进。
4. 网络协作：节点列举、消息发送、广播、渠道消息、收件箱检查、点对点文档收发、身份查询、智能体互调。
5. 技能：技能列举、使用、创建、更新、导出、导入、分享、候选列举与提升。
6. 记忆与上下文：上下文层列举、上下文资产读写、记忆检索、工程校验。
7. 目标与决策：目标创建、继续、暂停、后台继续、计划创建与更新、决策创建与执行。
8. 界面控制：标签切换、打开会话、打开设置、打开钱包、提示气泡、返回。
9. 浏览器与桌面：网页打开与解析、截图、点击、输入、按键、执行脚本；桌面截图、点击、输入、组合键、滚动、剪贴板、前台应用、启动应用。
10. 人机交互：提问（可带选项与超时）。
11. 外部能力：模型上下文协议工具列举与调用、外部引擎委派、服务注册与发现、资源登记与转让、信誉查询与更新。
12. 存储与发布：内容寻址存储的写入、读取、列举，命名发布与解析。
13. 支付（可选）：钱包创建与导入、余额、转账、签名、授权支付、按次付费信息购买与验真。
14. 自我改进：自我改进循环、版本检查。

## 6.5 节点间协议接口

1. 消息帧：包含发送方身份、接收方标识、消息类型、正文、时间戳与签名；接收方先验签后处理。
2. 消息类型：会话消息、广播消息、渠道消息、文档帧、任务委派帧、目标唤醒事件、好友与群组控制消息。
3. 文档帧：包含发送方身份、签名、内容标识与分片信息；接收端按签名与内容标识双重校验后入库。
4. 委派帧：包含能力要求、任务描述、超时与委派标识；响应包含执行者标识、产物内容标识与执行结果。
5. 唤醒事件：包含来源、关联标识、事件类型、事件标识与过期时间；必须依次通过五重校验才生效。
6. 寻址方式：以身份标识与公钥构成节点地址，支持直连地址、打洞地址与中继地址三种形式；中继地址由中继节点分配并在启动后复验。

## 6.6 接口约定

1. 命名：接口路径使用小写加连字符；工具名使用小写下划线；参数名使用小写下划线。
2. 返回：一律返回结构化结果，包含成功标志、数据与错误原因；错误原因面向使用者可读，不返回底层堆栈。
3. 状态码：受理类请求返回受理状态（202），查询返回正常状态（200），参数错误返回请求错误（400），权限拒绝返回禁止状态（403），不存在返回未找到（404），对端无响应返回超时状态（504）。
4. 版本：接口路径不带版本号，字段新增保持向后兼容；破坏性变更需同步升级路径与调用方。
5. 安全：所有本机接口默认仅监听本机地址；来自网络的请求必须携带有效签名；密钥类字段只写不读（读取时脱敏）。
