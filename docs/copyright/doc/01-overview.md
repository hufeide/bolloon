# 第一章 软件概述

## 1.1 软件名称与版本

本软件全称为「Bolloon 智能体软件」，简称「Bolloon」，登记版本号 V1.0。软件为本地优先、点对点协作的人工智能智能体软件，由服务端程序、命令行界面、浏览器界面、桌面客户端与移动端应用共同组成。

## 1.2 开发背景与目的

通用大模型助手普遍存在三个问题：一是会话结束即遗忘，无法持续积累用户的判断力；二是数据与上下文集中在厂商服务器，用户无法真正掌控自己的资料；三是单机能力有限，无法安全地在多台设备、多个用户之间协作。

本软件的目的，是让个人智能体从「会话即忘」升级为「持续学习 + 跨设备协作」，并在设计上坚持三条底线：

1. 本地优先：会话、记忆、技能、密钥全部存放在用户本机目录，删除本机数据即彻底删除。
2. 无中心服务器：节点之间通过点对点网络互相发现与直连，不依赖任何中心账号体系。
3. 可核查：每一次工具执行、外部唤醒、任务续跑都留下可查记录，失败时如实报错而不是假装成功。

## 1.3 软件主要内容与组成

软件由十二个功能模块组成，各模块职责如下：

1. 程序入口与命令分发模块：解析启动参数，分流到命令行模式、浏览器模式、桌面模式、后台守护模式等运行形态。
2. 启动引导与初始化模块：装配会话上下文、分层记忆、人格文档、项目状态，完成运行前的自检与就绪判定。
3. 智能体核心引擎模块：实现推理与行动迭代循环，管理工具注册、工具参数校验、步骤事件与最终答复。
4. 生态扩展协议模块：目标执行、判断力协议、模型上下文协议、子智能体、界面协议等扩展能力。
5. 大模型接入与上下文压缩模块：多供应商接入、提示词分层装配、上下文压缩与截断策略。
6. 约束层与安全模块：工具闸门、拒绝清单、权限模式、操作审计、隐私合规。
7. 点对点网络与身份模块：节点发现、地址穿透、中继转发、去中心化身份、签名消息、好友与群组。
8. 存储与运行态模块：初始化状态、定时任务、心跳、本机数据持久化与迁移。
9. 文档与知识处理模块：文档解析、知识整理、判断记录、工作流与语言服务。
10. 命令行界面与桌面外壳模块：终端交互界面渲染与桌面客户端封装。
11. 自研运行时包模块：独立发布的约束运行时包，提供工作流编排与约束求解能力。
12. 服务端与界面模块：本机 HTTP 服务与接口、浏览器端界面、移动端界面与移动端网关。

## 1.4 主要功能概述

软件提供下述主要功能：

1. 智能体对话与任务执行：把用户目标拆解为步骤，逐步调用工具完成，全程可观察、可中断、可续跑。
2. 多模型接入：支持多家大模型供应商，用户自带密钥，可在本机配置中切换。
3. 工具调用与文档处理：文件读写、命令执行、代码检索、网页浏览、桌面操作、文档解析与知识库沉淀。
4. 长期任务执行：目标、运行、检查点、恢复四段状态机，失败自动重试或转人工。
5. 技能体系：技能以标准描述文件沉淀、导入、分享，执行前校验技能快照。
6. 点对点协作：节点自动发现与直连、去中心化身份验证、跨设备会话同步、好友与群组协作。
7. 多端交互：命令行、浏览器、桌面、移动端四种形态，移动端支持扫码入网与无障碍自动操作。
8. 安全与合规：工具执行受权限闸门约束，密钥与私钥仅存本机，首次启动提供隐私同意与数据清除。

## 1.6 运行环境

1. 服务端与桌面端：Node.js 22 及以上运行时，支持 macOS、Windows、Linux。
2. 浏览器端：支持现代浏览器（Chromium 内核浏览器、Safari），界面采用原生页面技术实现，不依赖第三方前端框架。
3. 移动端：Android 10 及以上、iOS 16 及以上，采用原生外壳加本地页面容器的方式运行。
4. 存储：本机文件系统存放配置与会话数据，浏览器端使用本机数据库，分布式场景使用内容寻址存储。
5. 网络：支持局域网直连与中继转发两种链路，无公网环境时进入离线可用状态。
