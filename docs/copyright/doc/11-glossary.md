# 第十一章 术语表

| 术语 | 说明 |
| --- | --- |
| 智能体 | 能够理解目标、规划步骤并调用工具执行的程序实体；本软件的核心运行单元 |
| 迭代循环 | 智能体「推理—行动—观察」反复推进的工作循环，直到给出最终答复或达到步数上限 |
| 工具 | 智能体可调用的具体能力，如文件读写、命令执行、网页操作；调用前经参数校验与权限闸门 |
| 工具闸门 | 判定某次工具调用是否被允许的统一入口；默认只读放行、写入请示、危险拒绝 |
| 目标 | 用户提出的长期任务描述，附带完成判据与所需技能 |
| 判据 | 判定目标是否完成的明确条件；分用户给定并确认的判据与软件提出的候选判据 |
| 运行 | 目标的一次执行实例；运行上冻结判据，并记录证据与健康状态 |
| 检查点 | 运行过程中保存的进度与证据快照，用于中断后继续 |
| 监督器 | 负责创建运行、监控进度、处理唤醒与转人工的组件 |
| 外部唤醒 | 目标等待外部条件时登记等待条件，条件满足时被事件唤醒继续执行的机制 |
| 技能 | 以描述文件形式沉淀的可复用做法，包含适用条件与执行步骤 |
| 技能快照 | 长期任务执行前冻结的技能版本信息（名称、版本、内容指纹、来源、时间） |
| 技能门禁 | 运行开始前对技能快照的校验；不通过则不启动运行并转人工 |
| 记忆分层 | 把记忆分为人格层、项目层、会话层与知识层，按优先级装配进上下文 |
| 上下文压缩 | 上下文接近窗口上限时执行的折叠、摘要与截断处理 |
| 内容寻址 | 以内容哈希作为标识的存储方式，相同内容天然去重，便于分享与校验 |
| 去中心化身份 | 由本机生成密钥对得到的节点身份标识，用于签名与验签 |
| 点对点网络 | 节点之间直接互联、不依赖中心服务器的网络形态 |
| 中继 | 跨网段时转发数据的节点；内容仍以端到端签名为准，中继不能伪造 |
| 网关 | 全局智能体网络的登记与检索入口，节点入网后可被其他节点发现 |
| 好友与群组 | 节点之间的社交关系与多节点广播关系 |
| 多设备目录 | 记录同一身份下多台设备标识与公钥的目录，用于跨设备同步 |
| 会话 | 一次围绕主题的连续对话，包含消息序列与上下文 |
| 渠道 | 会话的组织方式，可对应不同智能体或不同主题 |
| 事件流 | 服务端向界面单向推送执行过程数据的通道，用于流式显示与轨迹渲染 |
| 幂等 | 同一操作重复执行只产生一次效果；副作用工具带幂等键保证这一点 |
| 原子写入 | 先写临时文件再整体替换，保证文件要么完整要么保持原状 |
| 熔断 | 连续失败后暂停该任务的重试，避免无效消耗 |
| 降级 | 某项依赖不可用时切换到较弱但可用的方式，并在界面或日志中明示 |
| 无障碍服务 | 移动系统提供的界面操作授权通道，用于智能体代用户操作界面 |
| 初始化就绪 | 身份、模型、密钥、连通性均验证通过的状态；未就绪不允许创建长期任务 |
| 消融实验 | 对能力做开启与关闭对照，验证能力确实由对应实现提供的实验方法 |
| 注册版本号 | 软件著作权登记时填写的版本号（本软件为 V1.0），与代码内部版本号相互独立 |
