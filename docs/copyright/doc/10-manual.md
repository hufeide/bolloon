# 第十章 用户手册

## 10.1 安装

### 10.1.1 通过包管理器安装（推荐）

1. 安装 Node.js 22 或更高版本（可从 Node.js 官网下载长期支持版，或使用系统包管理器安装）。
2. 执行全局安装命令：`npm install -g @bolloon/bolloon-agent`。
3. 安装完成后终端输入 `bolloon` 即可启动。

### 10.1.2 通过一键脚本安装

1. macOS 与 Linux：`curl -fsSL https://raw.githubusercontent.com/logos-42/bolloon/master/scripts/install.sh | sh`。
2. Windows：以管理员身份运行 PowerShell，执行仓库中的安装脚本（`scripts/install.ps1`）。

### 10.1.3 从源码运行

1. 克隆仓库：`git clone https://github.com/logos-42/bolloon.git`，并进入目录。
2. 安装依赖：`npm install`。
3. 全量构建：`npm run build:all`。
4. 启动：`npm start`（或开发模式 `npm run dev`）。

### 10.1.4 移动端安装

1. Android：安装发布的安装包；安装后按首次启动提示完成隐私同意与初始化。
2. iOS：通过官方渠道安装；iOS 16 及以上支持系统级快捷指令入口。
3. 移动端可选能力（无障碍自动操作、附近设备）需在系统设置中授权；重装应用后授权会重置，需要重新开启。

## 10.2 启动与运行形态

| 命令 | 说明 |
| --- | --- |
| `bolloon` | 交互模式（默认，终端界面） |
| `bolloon --web` | 浏览器模式，启动本机服务后由浏览器访问 |
| `bolloon --cli` | 强制纯命令行模式 |
| `bolloon --help` | 查看全部命令与开关 |
| `bolloon setup` | 运行初始化向导 |
| `bolloon model key <供应商>` | 为指定供应商补充密钥（隐藏输入，不回显） |
| `bolloon update` | 检查并执行版本更新 |

首次启动会自动进入初始化流程；若未配置模型密钥，程序停在「待填凭证」阶段并给出下一步提示。

## 10.3 初始化向导

1. 填写称呼：用于智能体对用户的称呼。
2. 选择模型供应商：支持多家常见供应商。
3. 填写密钥：隐藏输入，仅保存在本机配置文件，界面与日志均不回显。
4. 选择模型名称，可自定义接口地址以接入兼容服务。
5. 连通性测试：测试失败时按错误类型给出原因（凭证错误、网络不可达、额度不足等）与恢复动作。
6. 完成就绪判定：未就绪状态下不能创建长期任务，避免产生无意义的运行。
7. 中断后继续：向导任何阶段中断，重新执行 `bolloon setup` 或 `--setup-resume` 可从已完成阶段继续；配置损坏时用 `--setup-repair` 修复、用 `--setup-reconfigure` 重新配置。

## 10.4 命令行使用方法

1. 直接输入自然语言即可与智能体对话；输入以斜杠开头的命令用于控制。
2. 常用控制命令：查看帮助、查看工具清单、切换模型、查看初始化状态、查看目标与运行、查看问题列表与回答。
3. 引用输入：输入时可引用文件、渠道与技能，引用后内容随消息一并提交。
4. 中断与继续：任务执行中可中断；被中断的任务可继续执行。
5. 执行轨迹：终端界面实时显示每一步的工具调用与结果，便于观察与排查。
6. 一次性执行：使用 `--prompt` 传入提示词可完成一次性任务而不进入交互界面。

## 10.5 浏览器界面使用方法

1. 以 `bolloon --web` 启动后，终端会输出本机访问地址（含端口号）。
2. 页面分区：会话、智能体、网络与节点、技能、目标与长期执行、设置。
3. 会话页：左侧为会话列表，右侧为对话区；回复流式显示，执行轨迹可展开查看。
4. 智能体页：创建与管理本机智能体，设置名称、人格与能力。
5. 网络页：查看已连接节点、自身可拨入地址、好友与群组；可复制连接信息供移动端使用。
6. 技能页：查看已安装技能、导入与导出、生成分享链接。
7. 目标页：查看目标与运行状态，确认判据、提交候选判据、唤醒、暂停与中止。
8. 设置页：模型配置、隐私政策、清除本机数据（注销）、版本信息。

## 10.6 桌面客户端使用方法

1. 安装后双击启动，应用会自动选择空闲端口并在窗口内加载界面。
2. 首次启动进入初始化引导；已完成初始化则直接进入会话界面。
3. 支持托盘常驻、全局唤起与开机启动；关闭窗口后仍可在后台执行长期任务与定时任务。
4. 若启动异常，可在应用的日志目录查看启动日志，或改用浏览器模式访问同一数据。

## 10.7 移动端使用方法

1. 首次启动：阅读隐私政策并选择同意后进入应用；选择不同意则停留在说明页，不收集任何信息。
2. 页面：主页（会话）、索引（历史会话）、搜索（本机智能体、好友、全局智能体三源检索）、好友、网络、技能、设置。
3. 加入网络：网络页提供三种方式——选择附近设备、扫描电脑端二维码、粘贴链接兜底。
4. 电脑端同步：在设置页选择「从电脑端同步」可拉取电脑端技能与智能体清单。
5. 本机智能体：移动端可在本机运行智能体循环，回复区展示执行轨迹；回复支持复制、评价、分享、重新生成与分支。
6. 无障碍自动操作：在系统设置中开启对应的无障碍服务后，智能体可代用户操作界面；未授权时相关工具会如实提示不可用。
7. 清除数据：设置页「清除本机数据（注销）」即时删除本机身份、智能体、会话与消息、支付记录与本机键值。

## 10.8 技能使用方法

1. 查看技能：命令行查看技能清单，或浏览器与移动端的技能页。
2. 使用技能：直接描述任务，智能体会按技能声明的适用条件自动选用；也可显式指定技能名称。
3. 创建技能：让智能体把一段可复用的做法沉淀为技能，写入本机技能目录。
4. 导入技能：支持本地技能包、内容标识与分享链接三种来源；导入具备事务性，失败会回滚并保留旧版本。
5. 分享技能：把技能打包上传得到分享链接，也可通过点对点通道直接发送给好友。
6. 版本保护：当本机版本不低于来源版本时会拒绝覆盖，避免被静默降级；确需覆盖时可显式强制，旧版本会自动备份。

## 10.9 长期任务使用方法

1. 提出目标：用一句话描述目标；软件会记录完成判据。若未给判据，软件会提出候选判据请你确认——未确认的候选判据不会让任务被判定完成。
2. 开始执行：任务由监督器执行，期间可随时暂停、继续或中止；必要时可让任务转后台继续。
3. 观察进度：在目标页查看运行状态、证据与未决事项。
4. 等待外部结果：任务等待外部条件时不会空转，条件满足或超时后自动唤醒；超时会转人工处理，不会无限等待。
5. 完成判定：需同时满足判据存在且已确认、判据全部满足、存在证据、无未决事项、最近一次运行健康，任务才会被标记完成。

## 10.10 网络协作使用方法

1. 启动联网：软件启动时自动尝试联网；网络页可查看已连接节点与自身可拨入地址。
2. 添加好友：通过节点标识、扫描二维码或附近设备列表发起申请；对方接受后即可互发消息与文档。
3. 二维码入网：电脑端生成二维码，移动端扫描即可建立连接。
4. 任务委派：可把任务委派给具备相应能力的对端智能体；能力不匹配时不会转派给其他智能体，而是明确返回无匹配。
5. 离线说明：无公网环境时仅支持局域网协作，界面会明确提示，不会假装可用。

## 10.11 环境变量（可选）

| 变量 | 用途 |
| --- | --- |
| `BOLLOON_HOME` | 指定本机数据目录（默认用户主目录下的 `.bolloon`） |
| `BOLLOON_LLM_PROVIDER` | 指定使用的模型供应商 |
| `OPENAI_API_KEY` / `DEEPSEEK_API_KEY` / `ANTHROPIC_API_KEY` | 对应供应商的密钥（也可在初始化向导中填写） |
| `BOLLOON_PORT` | 指定服务端口（默认自动选择空闲端口） |
| `BOLLOON_CHROME_PATH` | 指定浏览器可执行文件路径（用于网页自动化能力） |
| `BOLLOON_CRON` | 设为 0 关闭定时任务调度 |
| `BOLLOON_SUPERVISOR` | 设为 0 关闭长期任务监督器 |
| `BOLLOON_SKIP_KUBO` | 设为 1 跳过本地内容寻址存储服务的自动安装 |

## 10.12 升级与卸载

1. 检查更新：命令行执行更新检查子命令，或在界面查看版本信息。
2. 升级：以包管理器方式安装的使用对应升级命令；以脚本安装的重新执行安装脚本。
3. 数据保留：升级不会删除本机数据目录；如需彻底清理，使用设置页的清除数据功能或手动删除数据目录。
4. 卸载：以包管理器方式安装的执行卸载命令；桌面端卸载应用；移动端卸载应用。卸载前建议先导出需要保留的技能与文档。

## 10.13 常见问题与排查

| 现象 | 原因与处理 |
| --- | --- |
| 启动后提示未配置模型 | 运行初始化向导并填写有效密钥；也可能是密钥失效或额度不足，向导的连通性测试会给出具体分类 |
| 界面一直显示执行中 | 检查是否等待外部结果或等待人工回答；目标页会显示等待原因，超时后会自动转人工 |
| 移动端看不到电脑端 | 确认两台设备在同一网络；或改用扫码入网；仍不可达时使用粘贴链接兜底 |
| 移动端无障碍功能不可用 | 需在系统设置中开启对应服务；重装应用后需重新开启 |
| 技能导入失败 | 界面会给出失败原因（包损坏、路径非法、版本更低等）；修复后重试，旧版本不会被破坏 |
| 任务未判定完成 | 检查判据是否已确认、是否全部满足、是否有证据、是否有未决事项 |
| 定时任务不执行 | 检查是否处于安静时段或主任务执行中（会被推迟并补跑）；查看任务执行记录与监控日志 |
| 配置损坏 | 使用修复子命令按提示修复，或重新配置；程序不会静默回退默认值以免覆盖用户数据 |
| 网页自动化不可用 | 确认本机已安装浏览器，或用环境变量指定浏览器路径 |

## 10.14 使用建议

1. 先完成初始化再创建长期任务，避免任务因缺少模型或技能而空转。
2. 为长期任务提供明确判据，可显著提高完成判定的可靠性。
3. 定期查看技能与知识整理结果，把可复用的做法沉淀为技能。
4. 涉及写入、命令执行与付费的操作请在授权前确认范围，必要时降低授权级别。
5. 重要数据定期备份本机数据目录（密钥文件请单独妥善保管）。
