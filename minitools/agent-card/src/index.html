边界说明

· 小工具不能联网: 容器禁用 fetch / WebSocket 等,也没有网络类原生接口。
· 原生只开放 4 个能力: 发布笔记 / 存相册 / 跳转 App 页 / base64 转临时文件 —— 没有"入网"或"发消息"接口。
· 所以真正的入网与交流由 App 侧智能体完成: 这个工具负责采集身份、生成名片、把入口递出去。
· 本地数据不保证永久保留 (容器可清理),重要内容请自己备份交接串。

本机执行轨迹

记录这个工具里真实发生过的动作与结果(保存身份 / 生成名片 / 存相册 / 发笔记 / 跳转 / 导入联系人 / P2P 校验…),包括失败原因。它只写在本机,不上传 —— 因为小工具不能联网。

要智能体"真执行工具、操作本机"的轨迹? 那一端在 App / 电脑上的智能体里(小工具不能联网、也没有文件与命令能力)。 在 Bolloon 里跑 bolloon trace <runId>(或对话里 /trace <runId>),把输出粘到下面 「导入轨迹文本」,就能看到对方智能体在哪台机器上执行了哪些工具、结果与耗时。
